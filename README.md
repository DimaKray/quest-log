# Квест-лог

Планувальник задач з ігровим шаром: задачі = квести, великі цілі = боси, продуктивність качає героя.

## Структура

```
packages/engine   чисте TS-ядро правил гри (XP, рівні, стрики), без React і БД
apps/web          Next.js застосунок (наступний крок)
apps/api          бекенд (пізніше)
```

## Команди

```bash
npm install
npm test            # unit-тести рушія
npm run typecheck
```

## Статус

- [x] Етап 1: рушій правил (XP, рівні, стрики) + тести
- [ ] Етап 2: боси й досягнення в рушії
- [ ] Етап 3: Next.js, перший екран
